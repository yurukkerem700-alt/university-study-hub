# university-study-hub

Üniversite öğrencileri için konu başlık bazında detaylı notlar, sınav hazırlığı ve kaynak arşivi.

## Özellikler
- Bölüm, sınıf, konu ve içerik tipi filtreleri
- Ders notu ve sınav hazırlık kaynakları arama alanı
- Öğrenci ve öğretmen odaklı görünüm
- En çok indirilen, beğenilen ve katkı sağlayan öğrenciler panosu
- Profesyonel, sade ama canlı tasarım

## Çalıştırma
1. Proje klasörüne girin.
2. Aşağıdaki komutu çalıştırın:
   ```bash
   python -m http.server 8000
   ```
3. Tarayıcıda şu adrese gidin:
   `http://localhost:8000`

## Yapı
- `index.html` – arayüz yapısı
- `styles.css` – profesyonel tasarım ve responsive düzen
- `app.js` – filtreleme, arama ve etkileşimler
